# PRACTICA

Carpeta para practicar Spring Boot por tu cuenta, separada de los proyectos de clase.

Cada ejercicio va en su propia subcarpeta (un proyecto Maven por carpeta).

| Carpeta | Contenido |
|---|---|
| `examen-ut04-cine` | Solución completa del examen UT04 (Spring Boot + JPA + Thymeleaf, películas de un cine). Paquete base `com.ejemplo.cine`. |

Para abrir uno en STS: File › Import › Existing Maven Projects › elige la subcarpeta.
