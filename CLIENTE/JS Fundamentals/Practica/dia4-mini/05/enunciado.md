# 5 · Mensaje desde la ventana hija
Al pulsar "Abrir" se abre `hija.html` (300x200). Allí hay un input `texto` y un botón "Enviar".
- Si el input está vacío: alert "Escribe un mensaje" y la ventana sigue abierta.
- Si no, el texto se escribe en el div `mensaje` de la principal, en azul, y la hija se cierra.
Un js por página: `js/principal.js` y `js/hija.js`.
