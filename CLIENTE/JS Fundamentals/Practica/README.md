# Práctica Cliente (preparación del examen)

Formato del examen (según lo que dijo la profesora): te dan el HTML y tú haces el JavaScript.
Aquí pasa lo mismo: en cada carpeta el HTML ya está hecho; **solo editas `ejercicio.js`** (o los .js indicados).

Temario: ventanas, temporizadores, eventos, formularios y DOM.

## Cómo trabajar
1. Lee `enunciado.md` de la carpeta.
2. Abre `index.html` en el navegador y programa en `ejercicio.js`.
3. Cuando termines (o te atasques), pásame tu JS y te lo corrijo y apunto fortalezas y debilidades.
